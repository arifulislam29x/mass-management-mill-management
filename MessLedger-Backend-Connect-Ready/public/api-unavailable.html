MessLedger Backend সংযুক্ত হয়নি

এই Netlify সাইটে Frontend প্রকাশিত হয়েছে, কিন্তু API Backend এখনো সংযুক্ত নেই।

Express Backend-টি Render, Railway বা Persistent Disk-সহ কোনো Node.js Hosting-এ চালু করুন। এরপর Netlify Environment Variables-এ VITE_API_BASE_URL হিসেবে Backend-এর মূল URL দিন এবং নতুন করে Deploy করুন।

Backend-এর /api/health ঠিকভাবে কাজ করছে কি না যাচাই করুন।
